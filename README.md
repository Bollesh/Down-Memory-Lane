# Down Memory Lane: InspireWorks AI Image Slack Bot

A Slack bot that creates imaginative childhood photos of you. Mention it with a description:

> **@Down Memory Lane** my 5-year-old self on a beach

It replies in the same thread with a realistic photo, generated by a Flux LoRA model trained on your own photos and hosted on Replicate.

## Features

- **Same-thread replies.** Each request gets its own thread. The bot works in channels (by mention) and in direct messages.
- **Instant feedback.** Your message gets a ⏳ reaction straight away, plus a "Creating your memory…" note. When the image is ready, the reaction changes to ✅ (or ❌ if something went wrong).
- **Prompt helper.** Casual requests ("me at 7 riding a bike") become full prompts. The helper adds your model's trigger word, an age description ("a 7-year-old child") and a nostalgic photo style. The prompt it used appears under the image.
- **Regenerate button.** Creates a new take on the same description, in the same thread.
- **Friendly errors.** Safety-filter blocks and model failures are explained in plain words in the thread.

## How it works

```
Slack ──(Socket Mode websocket)──► app.py ──► prompts.py ──► generator.py ──► Replicate (your Flux LoRA)
  ▲                                                                                │
  └────────────── image uploaded to the same thread (files_upload_v2) ◄────────────┘
```

- **No public URL needed.** The bot uses **Socket Mode**: it opens an outgoing websocket to Slack, so no ngrok or server is required.
- **Slow generation is fine.** Bolt acknowledges each event immediately, and generation (about 20–40 s) runs afterwards in Bolt's worker threads.

| File | Purpose |
|---|---|
| `app.py` | Slack listeners: mentions, DMs, Regenerate button; posting results |
| `prompts.py` | Prompt helper: description → full prompt with trigger word, age and style |
| `generator.py` | Calls the trained model on Replicate and returns the image |
| `manifest.yml` | Slack app definition: scopes, events, Socket Mode |
| `config.py` | Loads settings from `.env` |

## Setup

### 1. Python

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

### 2. Train your model on Replicate (start this first; it takes about 20–30 minutes)

1. Put about 20 photos of just you in a zip, with different settings, lighting and angles.
2. On replicate.com, open the **ostris/flux-dev-lora-trainer** training page. Upload the zip as `input_images`, enter a unique `trigger_word` (e.g. `JNTOK`), and choose a destination model, e.g. `your-username/down-memory-lane`.
3. When training succeeds, set these in `.env`:
   - `REPLICATE_MODEL=your-username/down-memory-lane`
   - `TRIGGER_WORD` (the same word you used in training)
   - `REPLICATE_API_TOKEN` (from replicate.com/account/api-tokens)

### 3. Create the Slack app

1. Go to api.slack.com/apps → **Create New App** → **From an app manifest**, choose your workspace, and paste `manifest.yml`.
2. Under **Basic Information → App-Level Tokens**, create a token with the `connections:write` scope. Put it in `.env` as `SLACK_APP_TOKEN` (`xapp-…`).
3. Under **Install App**, install the app to your workspace. Put the Bot User OAuth Token in `.env` as `SLACK_BOT_TOKEN` (`xoxb-…`).
4. In Slack, invite the bot to a channel with `/invite @Down Memory Lane`.

### 4. Run

```bash
python app.py
```

Then, in the channel, try:
- `@Down Memory Lane my 2-year-old self in my house's backyard`
- `@Down Memory Lane my 5-year-old self on a beach`
- `@Down Memory Lane my 10-year-old self in a classroom`

## Settings (`.env`)

| Variable | Meaning |
|---|---|
| `SLACK_BOT_TOKEN` | Bot token (`xoxb-…`) |
| `SLACK_APP_TOKEN` | App-level token for Socket Mode (`xapp-…`) |
| `REPLICATE_API_TOKEN` | Replicate API token |
| `REPLICATE_MODEL` | Your trained model, `owner/name` (latest version) or `owner/name:version` |
| `TRIGGER_WORD` | The trigger word used in training |

To tune image generation (aspect ratio, LoRA strength, `dev` vs `schnell`), edit `GENERATION_INPUT` in `generator.py`.
